# Changelog

User-visible changes to Awake are recorded here. This project follows the general format of [Keep a Changelog](https://keepachangelog.com/en/1.1.0/).

## [Unreleased]

### Added

- 3-step progressive Get Started onboarding wizard with local AI and developer tool discovery without telemetry or cloud sync.
- Native macOS Settings window featuring General preferences, Automations management, and About information.
- Distributable compressed `.dmg` disk image creation via `make dmg` and `scripts/create-dmg.sh`.
- Animated, state-diffed SwiftUI Menu Bar Popover with Reduce Motion support.
- Stickman vector mascot icon and high-resolution multi-size `.icns` packaging.
- Open source contribution, support, and security guidance.
