# Support

## Where to ask

- **Bug reports:** use the [bug report form](https://github.com/ChuBu0012/awake/issues/new?template=bug_report.yml).
- **Feature requests:** use the [feature request form](https://github.com/ChuBu0012/awake/issues/new?template=feature_request.yml).
- **Security vulnerabilities:** follow [SECURITY.md](SECURITY.md); do not post them publicly.
- **Contributing:** see [CONTRIBUTING.md](CONTRIBUTING.md).

For general questions, check the README and search existing issues before opening a new one. Include the Awake version, macOS version, Mac architecture (Apple Silicon or Intel), what you expected, and what happened. Remove usernames, tokens, paths, and other private information from logs before sharing them.

Awake is maintained by volunteers. Support is provided on a best-effort basis, with no guaranteed response time.
